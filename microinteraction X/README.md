# Small moves

14 интерактивных микроисследований интерфейса для @sekenoov. React + Motion + Vite. Все сцены работают локально, внешние API не нужны.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://127.0.0.1:5173/. `npm run build` создаёт `dist/`.

## Управление

- Слева: выбор из 14 живых сцен.
- **Play sequence**: пятисекундная демонстрация состояния и возврат к началу.
- **Reset**: сброс текущей сцены.
- **Copy post**: английская подпись для выбранного поста.
- **The week**: все 7 пар и подписи.
- Кнопка разворота справа над сценой: чистый режим записи.
- В чистом режиме панель внизу появляется при наведении. Escape возвращает студию.
- Пробел запускает последовательность, когда фокус на странице. Стрелки влево/вправо переключают сцены; при фокусе на слайдере стрелки управляют им.
- Слайдеры поддерживают клавиатуру. Hold to send работает удержанием мыши, касания, Space или Enter. Раннее отпускание отменяет действие.
- Ссылка на конкретную сцену: `?study=peel`. Добавить `&capture=1` для записи.

## Запись для X

Открыть чистую сцену, включить запись области экрана встроенным рекордером, нажать пробел и убрать курсор за область записи. Обрезать запуск и конец. Для ролика около 10 секунд записать два пятисекундных повтора. Полноценного экспорта MP4 внутри приложения нет.

`CONTENT-PLAN.md` содержит 14 сюжетов, сценарии записи и подписи. Идеи, ограничения и фактически использованные материалы описаны в `DESIGN-SOURCES.md`.

## Границы прототипа

AI-ответы, документы, сообщения и история являются авторскими примерами. Никакие данные не отправляются. Состояние сцен сбрасывается при перезагрузке; выбранная сцена сохраняется в URL. Автопостинга и автоматического расписания нет. Настройка reduced motion системы учитывается.
